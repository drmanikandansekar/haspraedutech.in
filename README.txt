HasPra EduTech Website — GitHub + Vercel

FILES
- index.html: website homepage (includes the embedded logo)
- vercel.json: Vercel configuration

DEPLOY WITH GITHUB
1. Extract this ZIP file.
2. Open your GitHub repository.
3. Upload index.html and vercel.json to the repository root.
4. Commit the changes.
5. If the repository is already connected to Vercel, deployment should start automatically.
   Otherwise, sign in at https://vercel.com, choose Add New > Project, import the GitHub
   repository, set Framework Preset to Other, leave Build Command and Install Command empty,
   set Output Directory to ., and click Deploy.

CUSTOM DOMAIN
In Vercel, open Project Settings > Domains and add www.haspraedutech.in.
Follow the DNS instructions Vercel provides.

No npm install or build command is required for this static HTML site.
